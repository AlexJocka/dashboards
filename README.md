# Дашборды Excel-отчётов

Локальное приложение Flask. Загружает до 20 файлов `.xlsx` (каждый до 10 МБ), определяет форму по содержимому и открывает `/dashboards`. Вспомогательная сводка FEX и нераспознанные файлы остаются на странице загрузки. Загруженные книги обрабатываются в памяти и не сохраняются.

Для F02A «Целевые студенты: свод» доступны карточки показателей, сравнение плана и договоров по вузам, распределение статусов, таблица, фильтры по году начала обучения, вузу и программе, выгрузка выбранных строк в CSV. Пустые ячейки отличаются от нулей. Блок «СПРАВОЧНО:» исключён из расчётов. Поддерживается структура приложенного шаблона, в которой основные заголовки занимают A:S и начинаются в строке 5; шапка может смещаться в пределах первых 30 строк.

Для F01 отображается ранее реализованный показатель обученных по месяцам. Для остальных распознанных форм показывается сообщение об отсутствии визуализации. При загрузке нескольких отчётов на дашборде доступен выбор файла.

## Демонстрация

На главной странице нажмите **Открыть демо-дашборд**. Файл `examples/Зафарова_демо.xlsx` - копия исходного шаблона с семью случайными записями для трёх вузов и двух годов начала обучения. Данные помечены как демонстрационные в книге и интерфейсе. Исходная книга не изменялась. Файл также можно скачать через интерфейс и загрузить обычным способом.

Контрольные суммы демо: план приёма 276, адресные квоты 242, договоры 138, продолжают обучение 122, трудоустроены 11, расторгнуты 5. При выборе 2024 года: 3 строки, 61 договор. При дополнительном выборе МАИ: 1 строка, 18 договоров.

Графики строятся локальным JavaScript и SVG без CDN и дополнительных библиотек. Интернет для работы страницы после установки Python-зависимостей не нужен.

## Оформление ОДК

Подключены предоставленные дизайн-токены, базовые стили, компоненты, стили четырёх экранов и логотип. Общая шапка и меню находятся в `templates/base.html`, исходные CSS-компоненты - в `static/css/`, адаптация графиков и загрузчика - в `static/dashboard.css`. Логотип - `static/images/odk-logo-full.png`. Шрифты выбираются из установленных локально Stolzl, Jost, Calibri, Arial; внешняя загрузка Google Fonts отключена.

Разделы: `/summary` - состав текущей загрузки; `/training` - отчёты F01; `/dashboards` - показатели и графики с выбором файла; `/data-quality` - результаты чтения, размеры листов и замечания. Статические примеры чисел из макетов заменены данными загрузки. Реестр отдельных студентов, ролевая модель, сравнение версий и история импортов не добавлены: в исходной F02A содержатся сводные показатели. Поиск по вузу, программе и специальности фильтрует карточки, графики и выгружаемый CSV.

## Запуск

На Windows:

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

На macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000. Для запуска тестов: `python -m unittest discover -s tests -v`.

## Хранение результатов и ограничения

Нормализованные результаты хранятся на сервере в памяти до двух часов, максимум 32 набора загрузок. Браузер получает только идентификатор в подписанной cookie. Обновление страницы сохраняет доступ к последнему набору; перезапуск приложения очищает результаты. При необходимости задайте постоянный ключ через переменную окружения `DASHBOARDS_SECRET_KEY`.

- Профили распознавания составлены по документу `пд.docx` и сверены с 20 книгами из `Downloads/tables`: 19 отчётов и вспомогательная сводка FEX распознаются по заголовкам и листам. Это проверка на имеющихся примерах; новые версии шаблонов могут отличаться.
- Для F02A нужно сохранять порядок столбцов исходного шаблона. Другие версии формы могут потребовать адаптации.
- Формулы Excel читаются по сохранённым значениям: openpyxl не пересчитывает формулы. Если в загруженной книге нет сохранённого результата формулы, показатель будет отсутствовать.
- Файлы `.xls` старого формата и архивы не поддерживаются.
- Соответствие 18 структурных вариантов официальным 12 формам пока предварительное.
