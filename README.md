# Черновик просмотра Excel-отчётов

Локальная веб-страница на Flask. Загружает до 20 файлов `.xlsx` (каждый до 10 МБ) и определяет форму по содержимому. После загрузки распознанной отчётной формы открывается `/dashboards` с сообщением о разработке, даже если числовые ячейки пока пустые. Вспомогательная сводка FEX и нераспознанные файлы остаются на странице загрузки. Файлы обрабатываются в памяти и не сохраняются.

## Запуск

На Windows:

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

На macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000. Для запуска тестов: `python -m unittest discover -s tests -v`.

## Что пока черновое

- Профили распознавания составлены по документу `пд.docx` и сверены с 20 книгами из `Downloads/tables`: 19 отчётов и вспомогательная сводка FEX распознаются по заголовкам и листам. Это проверка на имеющихся примерах; новые версии шаблонов могут отличаться.
- Разбор показателей реализован для F01. Остальные известные формы пока показываются как предварительно распознанные, без графиков.
- Файлы `.xls` старого формата и архивы не поддерживаются.
- Перед полноценной реализацией нужно согласовать, как 18 структурных вариантов соответствуют официальным 12 формам, и получить исходные книги для проверки.
